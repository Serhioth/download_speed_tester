# download-test

Небольшой Python-скрипт для измерения скорости скачивания по HTTP/HTTPS. Он несколько раз загружает содержимое по указанной ссылке, выводит результаты каждого запроса и рассчитывает итоговые показатели всей серии.

## Возможности

- Последовательное скачивание по ссылке: по умолчанию 10 запросов.
- Потоковое чтение ответа без сохранения скачанного файла на диск.
- Автоматический переход по редиректам.
- Измерение объёма данных, времени запроса и скорости скачивания.
- Вывод результатов в консоль и запись в `download_speed.log`.

## Требования

- Python 3.14 или новее.
- `uv` для установки зависимостей и запуска. Также можно использовать `pip`.
- Доступ к HTTP/HTTPS-ресурсу, с которого будет скачиваться содержимое.

## Установка и запуск

В каталоге проекта выполните:

```bash
uv sync --locked
uv run main.py
```

После появления приглашения `Ссылка:` вставьте прямую ссылку на файл и нажмите Enter. Скрипт выполнит 10 скачиваний и выведет сводку.

Если передать ссылку на веб-страницу, скрипт измерит загрузку её ответа, а не файлов, на которые она ссылается.

### Запуск без uv

Создайте виртуальное окружение и активируйте его:

```bash
python -m venv .venv
```

Linux / macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимость и запустите скрипт:

```bash
python -m pip install "httpx>=0.28.1"
python main.py
```

Убедитесь, что команда `python` использует Python 3.14 или новее. Установка через `uv sync --locked` использует версии зависимостей из `uv.lock`; установка через `pip` выше не использует этот файл.

## Количество скачиваний

При интерактивном запуске выполняется 10 запросов. Другое количество можно задать при вызове функции из Python:

```python
from main import main

main("https://example.com/file.bin", try_count=3)
```

Замените адрес на рабочую ссылку. `try_count` должен быть положительным целым числом.

## Как рассчитываются результаты

Для каждого скачивания выводятся:

- **Размер** — объём данных, прочитанных из ответа.
- **Время запроса** — время от начала запроса до завершения чтения ответа, включая ожидание первых данных.
- **Скорость скачивания** — размер ответа, делённый на время от получения первого блока данных до завершения чтения.

В итоговой сводке указываются число запросов, среднее время запроса, общий объём скачанных данных и средняя скорость. Средняя скорость рассчитывается как общий объём данных, делённый на сумму времени скачивания, а не как среднее арифметическое скоростей отдельных запросов.

В логах используются обозначения `MB` и `MB/s`, но расчёт выполняется через `1024 × 1024` байт: фактически это MiB и MiB/s.

Измерение зависит от выбранного сервера, размера ответа и состояния сети. Для маленьких ответов результат может быть завышен: время ожидания первого блока исключено из расчёта скорости, хотя его размер учитывается. Каждый запрос заново скачивает содержимое, поэтому 10 скачиваний файла размером 100 MiB дадут около 1 000 MiB данных.

## Логи и ошибки

Результаты дописываются в `download_speed.log` в текущем рабочем каталоге. Файлы `*.log` исключены из Git через `.gitignore`.

Для сетевых операций настроен тайм-аут 30 секунд; это не ограничение общей длительности скачивания. При сетевой ошибке или ошибочном HTTP-статусе серия прерывается с исключением `SpeedMeasurementError`, итоговая сводка не выводится.
